# Página demonstrativa PetShop AuMiaus

Exercício de página estática em HTML e CSS com seções Sobre, Serviços e Contato. O pet shop e os dados de contato são fictícios; a página não disponibiliza serviços reais.

## Executar

Abra `index.html` em um navegador. O arquivo `estilo.css` deve permanecer na mesma pasta. Não há dependências ou backend.

## Organização

A página passou a usar `index.html` como entrada e a referência real a `estilo.css`. A imagem `logo.png` não existia no repositório e foi removida do cabeçalho. O código antigo permanece no histórico Git.
